# 世界尺度与单位约定（写死，改之前先开 ADR）

> 3D RTS 最容易烂尾的地方就是尺度。所有数字在 S0 定死，后期改动的代价远大于前期纠结的代价。

## 基础约定

| 项 | 约定值 | 说明 |
| --- | --- | --- |
| 世界单位 | 1 unit = 1 米 | 全项目唯一标准，任何地方不得出现"这个模型单位是 100"的说法 |
| 坐标轴 | Godot 标准：+Y 向上，-Z 为物体正前方 | 模型导入必须统一朝向，机头朝 -Z |
| 手性 | 右手系 | 若原始 OBJ 是左手系，在 Blender 里翻转 X 后导出，不留在运行时处理 |

## 尺寸量级

| 对象 | 尺寸 | 说明 |
| --- | --- | --- |
| 小飞机 / 无人机 | 8 ~ 25 m | ou07 / ou09 / ou251 一类 |
| 护卫舰 / 中型舰 | 30 ~ 80 m | ou134 / ou137 / ou236 一类 |
| 主力舰 / 母舰 | 120 ~ 400 m | ou01 ~ ou06 / ou241 / ou238 一类 |
| 大型物体（小行星、空间站） | 50 ~ 800 m | ob1501 ~ ob1505 / ob1401 系列 |
| 交战距离（普通武器） | 500 m ~ 2 km | |
| 交战距离（远程/必杀） | 2 ~ 6 km | |
| 战场范围 | 20 ~ 40 km 见方 | 沿用原 2D 版 3000×3000 的体感比例放大 |

## 高度分层（AD-003）

| 层 | Y 高度 | 说明 |
| --- | --- | --- |
| 下 / L0 | -400 m | 避开上层障碍、贴大型天体飞行 |
| 巡航 / L1 | 0 m | 默认层，绝大多数交战发生在这里 |
| 高 / L2 | +400 m | 绕开低层障碍、抢占高位 |
| 排斥带 | ±150 m | 单位在巡航态会被推向本层中心，避免全场随机散布 |

层间距 400 m，用于避开 400 m 以下的物体；高于 800 m 的物体在**所有层**都构成障碍。

## LOD 切换距离（相对相机）

| 距离 | 使用 |
| --- | --- |
| < 800 m | LOD0 = SB 模型 |
| 800 m ~ 2.5 km | LOD1 = U 模型 |
| 2.5 km ~ 8 km | 单面 billboard |
| > 8 km | 纯图标（UI 层绘制） |

## 天空

天空**不参与世界尺度**。使用 Sky 资源（PanoramaSkyMaterial），不放置任何 mesh 天球。
详见 ADR-0006 与 docs/model-pipeline.md。

## 变更流程

改任何一行的量级（哪怕只是把交战距离从 2 km 改成 3 km）都必须：
1. 新开一份 ADR 说明为什么
2. 同步检查：模型缩放表、炮弹速度、射程资源、LOD 距离、相机缩放上下限、寻路膨胀半径
