# ADR-0001 双视图模式：2D 平面 + 3D 空间

- 状态：已采纳
- 日期：S0
- 决策者：用户 + DeepSeek

## 背景

原 2D 版（E:/ai_rts-main/rts_game）是连续坐标俯视 + 伪高度 z（屏幕投影 -z*0.22），
单位位置是 (x, y)，z 只是表现层的高度。参考游戏《银河天使》同时提供 2D 平面地图与 3D 空间战斗。

用户希望：既保留原版"拖拽地图"的指挥手感，又要真的 3D 效果。

## 选项

1. 只做 3D —— 玩家失去全局指挥视野，且原版操作习惯全部作废
2. 做两套模拟（2D 一套、3D 一套）—— 逻辑双写，必然发散
3. **一套 3D 模拟 + 两套镜头（视图适配器）**

## 结论

选 3。

- 模拟层永远只有一种数据形态：position: Vector3 + forward: Vector3 + speed: float
- 2D 模式 = 固定俯视正交相机 + 不同的 ViewProjection 实现
- 上层（选择、命令、UI、射程圈）只调 ViewProjection，不知道当前模式
- 模式切换是 0.4 s 相机插值，不做场景重载
- 默认"自动切换"：全局指挥 → 2D，接战/必杀/过场 → 3D

## 代价

- 必须严格守住"ViewProjection 是唯一差异点"这条纪律，一旦有业务代码写 if is_2d 就失败
- 2D 模式需要额外的"高度可视化"（阴影 + 高度角标 + 层亮度差），否则玩家看不出层
- 不能沿用原版的 -z*0.22 屏幕偏移（会让点选/框选与视觉不一致）

## 影响

docs/controls.md、docs/ARCHITECTURE.md 的 ViewProjection 接口、scripts/camera/、scripts/input/
