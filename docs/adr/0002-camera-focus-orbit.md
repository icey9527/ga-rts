# ADR-0002 相机：焦点轨道（禁止自由飞行）

- 状态：已采纳
- 日期：S0

## 背景

原 2D 版是仿射 screen↔world 映射 + 拖拽平移 + 滚轮缩放 + 边缘滚屏。
3D 里玩家问"视角怎么滑动比较好"，并担心失去拖拽地图的手感。

## 选项

1. 自由飞行相机（FPS 式 WASD + 鼠标看向）—— RTS 玩家会彻底迷失，且没有"向上拖"的直觉映射
2. 固定俯视 —— 等于放弃 3D
3. **焦点轨道相机**（Homeworld 式）：相机永远围绕一个焦点，所有操作都是移动/旋转这个焦点

## 结论

选 3。

- 焦点（focus point）是唯一的一等公民：位置 + 高度层 + 跟随目标
- 平移 = 焦点在相机地平面滑动（这就是原版"拖拽地图"在 3D 里的等价物，学习成本为零）
- 缩放 = 改相机到焦点的距离，**不改 FOV**（改 FOV 会产生透视变形，RTS 不可接受）
- 水平旋转 Q/E 或 Alt+左键拖拽；俯仰 Shift+滚轮或中键上下
- 聚焦 = 空格 / 双击单位，焦点平滑飞过去并临时跟随
- 2D 模式保持原版操作，零学习成本

## 护栏（必须实现，不是可选）

1. 相机不得穿地/穿物体；距离下限 30 m，太近自动抬升
2. 拉远超过 2.5 km 单位自动切 billboard，超过 8 km 切 UI 图标
3. 屏幕常驻"当前高度层 n/3"指示

## 代价

- 无法做出"从舰桥向外看"的沉浸视角（但那不是 RTS 需求）
- 焦点模型需要一套"焦点吸附"逻辑（吸附到选中单位群的中心），比自由相机复杂
