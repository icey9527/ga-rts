# ADR-0011 工具与游戏主代码分离，临时脚本单独目录

- 状态：已采纳
- 日期：S0

## 背景

用户："那就是你的工具脚本，你要维护好，这种临时性质脚本和长期性质脚本有区别的啊。
临时性质脚本就要临时文件夹弄，总之我们的这种工具啊脚本啊，一定要和游戏的主代码区分清楚。"

## 结论

```
tools/
├─ pipeline/   长期管线工具  （入 git，幂等，有 README）
├─ dev/        长期开发辅助  （入 git）
├─ ci/         自动检查      （入 git，本地与 CI 共用）
└─ temp/       临时脚本      （gitignore，跑完删）
```

铁律：

1. **scripts/（游戏主代码）绝不加载 tools/ 下任何东西**，不 preload、不 import、不依赖
2. 临时脚本一律 `tools/temp/`，允许硬编码、允许粗糙，但不入库、不被引用
3. 临时脚本的产物若要保留，必须提升为 pipeline 工具重跑一遍再落盘
4. 长期工具准入：有 README（输入/输出/依赖/耗时）、幂等、失败非零退出、路径可参数化

判定口诀：**"这个脚本明年还会有人跑吗？"**

## 代价

- 临时脚本每次要新建目录、跑完要自己删（多一步）
- 提升为长期工具需要补 README 与幂等性（多一点工作量）

## 影响

docs/tooling.md、.gitignore、tools/
