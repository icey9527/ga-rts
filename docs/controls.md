# 操作映射（双视图）

模式开关：Tab 循环 自动 → 锁 2D → 锁 3D。默认 **自动**。

## 自动切换规则（初版，可调）

| 触发 | 切到 |
| --- | --- |
| 进入战斗场景 / 战前部署 / 剧情对白 | 3D |
| 战斗结束、回到全局指挥 | 2D |
| 批量框选 ≥ 3 个单位并下达移动命令 | 2D |
| 任一所选单位进入武器射程 | 3D |
| 玩家释放必杀 / 主角舰受击 / 敌方增援入场 | 3D（临时，可被玩家锁定覆盖） |

切换过渡 0.4 s 平滑插值 + 音效提示，不做场景重载。

## 相机 —— 3D 模式（焦点轨道相机）

| 操作 | 输入 |
| --- | --- |
| 平移焦点 | 中键拖拽 / 右键拖拽 / WASD / 屏幕边缘 |
| 缩放 | 滚轮（改相机到焦点的距离，不改 FOV） |
| 水平绕行 | Q / E，或 Alt + 左键拖拽 |
| 俯仰 | Shift + 滚轮，或中键上下拖拽 |
| 聚焦所选 | 空格，或双击单位（焦点平滑飞过去 + 临时跟随） |
| 切换焦点高度层 | PageUp / PageDown |
| 停止跟随 | 任意平移输入 |

护栏：相机不得穿地/穿物体；距离 < 30 m 时自动抬升；拉远超过 2.5 km 单位自动切 billboard。

## 相机 —— 2D 模式（正交俯视，保留原版手感）

| 操作 | 输入 |
| --- | --- |
| 平移 | 右键拖拽 / 屏幕边缘 |
| 缩放 | 滚轮 |
| 切换显示的高度层 | PageUp / PageDown |

## 选择

| 操作 | 输入 |
| --- | --- |
| 点选 | 左键 |
| 加选 / 减选 | Shift + 左键 |
| 框选 | 左键拖拽 |
| 全选同屏我方 | 双击空地 |
| 选中同类 | Ctrl + 左键 |

## 命令

| 操作 | 输入 |
| --- | --- |
| 移动 | 右键点击 |
| 攻击 | 右键点击敌方单位 |
| 攻击移动 | A + 左键 |
| 停止 | S |
| 跟随 | 右键拖拽到目标 |
| 改高度层 | A + Shift + 左键（或在 3D 模式用 PageUp/PageDown） |

## 显示

| 操作 | 输入 |
| --- | --- |
| 暂停 | 空格（长按）/ Esc 菜单 |
| 射程显示 | R 切换 |
| 导航网格调试 | F3（仅调试构建） |
| 高度层高亮 | 按住 Alt |

> 以上按键在 S1 落地时写入 project.godot 的 Input Map，键位名统一用 snake_case（camera_pan、unit_select、cmd_move…）。
